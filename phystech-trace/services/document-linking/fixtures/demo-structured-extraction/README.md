Для интерфейса набор объединяет шесть настоящих upstream outputs из `../upstream-structured-extraction-1.2.0/` и четыре независимых JSON-сценария: документ неизвестного типа без пары, два договора с одинаковым номером без сторон и ссылающийся на них акт.
