# Phystech Trace — локальная русская копия

Локальная русская версия снимка главной страницы и доступных внутренних маршрутов сайта Transform9, полученного 12 ноября 2026 года. Веб-сайт сохраняет исходную Webflow-разметку, скрипты, стили и медиа; локальный слой задаёт русский язык, перевод интерфейса, логотип Phystech Trace и скрывает блок с номером телефона и кнопкой звонка Алексу. Исходные HTML, DOM после JavaScript и скачанные материалы находятся в `original/`; запуск — из `site/`.

## Запуск

Из `transform9-mirror/tools`:

```powershell
npm start
```

Откройте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Для остановки сервера нажмите `Ctrl+C` в терминале.

Если порт 4173 занят, задайте другой в PowerShell и используйте тот же адрес для аудита:

```powershell
# Терминал с сервером
$env:PORT = '4174'
npm start

# Второй терминал, из tools
$env:LOCAL_BASE_URL = 'http://127.0.0.1:4174'
npm run audit
```

Node-зависимости Playwright, pixelmatch и pngjs установлены локально в `tools/node_modules/`; Chromium установлен командой Playwright и находится в его пользовательском browser cache. Для повторного создания копии после обновления ресурсов:

```powershell
npm run mirror
npm start
```

Пересъёмка оригинала и pixel diff доступны командами `npm run capture` и `npm run compare`. `npm run capture` обращается к живому сайту.

## Содержимое

- `original/server-response.html` — HTML-ответ сервера главной страницы.
- `original/rendered-dom.html` — DOM после выполнения JavaScript и прокрутки страницы.
- `original/assets/` — неизменённые скачанные ресурсы с каталогами, сгруппированными по исходному хосту.
- `original/pages/` — HTML-ответы и DOM внутренних страниц.
- `site/` — локальные HTML-страницы и CSS/JS/медиа с перенаправленными путями, русский словарь и локальный логотип.
- `screenshots/` — кадры оригинала и копии для четырёх размеров, длинные скриншоты, мобильное меню и слайдер.
- `diff/` — pixel diff и наложения оригинала/копии.
- `reports/` — полный журнал сетевых ресурсов, проверки маршрутов, интерактивности, медиа и ограничений.
- `tools/` — скрипты захвата, сборки, локальной раздачи, проверки и сравнения.

Для обновления локальных HTML после правок сборщика выполните `npm run mirror` в `tools/`. Локальный словарь и логотип хранятся в `site/local-assets/` и остаются на месте.

Чтобы заново выгрузить видимый текст всех страниц в Markdown, запустите сайт (`npm start`), затем в другом терминале из `tools/` выполните `npm run export:text`. Файл экспорта будет сохранён как `site-text-export.md`; основной `site-text.md` можно использовать для подготовленного текста сайта.

Русский интерфейс применяется локально из `site/local-assets/translations.ru.json`; сайт при открытии не отправляет текст на сервис перевода. Словарь включает 956 исходных видимых строк, атрибутов и заголовков. Автоматический перевод может требовать редакторской вычитки, особенно в длинных юридических и медицинских текстах.

Сохранены 14 маршрутов: главная, Compare, Blog, Case Studies, Book a Demo, Terms of Use, Privacy Policy, HIPAA, четыре статьи блога и два кейса. Локальная проверка получила HTTP 200 для каждого.

## Локальные ограничения

Локальные страницы включают CSP, блокирующую внешние подключения. Все формы видимы, но их отправка перехватывается; телефонные ссылки не запускают вызов. Встроенное YouTube-видео использует локальную заставку и показывает уведомление о необходимости подключения к интернету. Основной MP4 и WebM сохранены. HubSpot/reCAPTCHA требуют внешнего сервера и локально не отправляют данные. Отдельный портал входа `portal.transform9.com` не удалось получить из текущей сети; его ссылка остаётся внешней.

Pixel diff не доказывает полное совпадение. Фон сайта и видео меняются между снимками, поэтому даже при одинаковой структуре пиксельный diff видит временные различия.
