# Исходный лендинг Phystech Trace

Каталог `site/` из https://github.com/artemnoor/phystech-trace-site восстановлен из commit `f1a0e58c2a0162a6276614220761fd8852d359a1` без изменений дизайна, структуры, текста, стилей и анимаций.

240 файлов совпадают с исходным репозиторием побайтно. Git SHA-1 главной страницы: `b9c394a02a63bf9d2022df34d9dd7a783a68b0bc`. Единственные исключения из исходных файлов — `logIn/index.html` и `register/index.html`: они содержат работающие формы, использующие Gateway API. Для них сохранены дополнительные `local-assets/auth.css` и `local-assets/auth.js`.

Webflow, GSAP, ScrollTrigger, Lenis, исходные вкладки, hover-эффекты, анимации и переходы восстановлены как в GitHub. Отдельные стили и скрипты полного редизайна и компонентных замен удалены из рабочего каталога. Сведения об импорте — в `upstream.json`, исходная документация — в `UPSTREAM.md`.

Общий запуск: `docker compose up --build -d` из `phystech-trace/`. Лендинг доступен по `/`, регистрация — `/register`, вход — `/logIn`, кабинет — `/app/`. Регистрация требует только непустые почту и пароль, без подтверждения почты, телефона и требований к сложности пароля.

По следующему запросу пользователя заменён только видеоблок главной страницы: локальный `local-assets/phystech-trace-demo.mp4` воспроизводит предоставленный ролик. Вся разметка за пределами одного `<figure>` совпадает с GitHub побайтно; исходные CSS и скрипты не менялись.
