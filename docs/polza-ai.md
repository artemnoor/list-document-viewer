# Polza AI / Gemma

## Конфигурация

Production-приложение читает конфигурацию при старте процесса. Docker Compose передаёт переменные Windows в контейнер:

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `POLZA_AI_ENABLED` | `true` | `false`, `0`, `no` или `off` отключает внешнюю модель |
| `POLZA_AI_API_KEY` | пусто | Ключ API Polza AI; без него provider выключен |
| `POLZA_AI_MODEL` | `google/gemma-4-26b-a4b-it` | Gemma 4 26B A4B Instruct |
| `POLZA_AI_BASE_URL` | `https://polza.ai/api/v1` | OpenAI-совместимый endpoint |

Ключ хранится в окружении Windows и передаётся контейнеру через Compose interpolation. Его не нужно добавлять в исходный код или коммитить в `.env`; локальный `.env` исключён из Git. После изменения env переменных пересоздайте приложение командой `docker compose up -d --force-recreate`.

Для локального `uvicorn app.main:app` используются те же переменные окружения. В `.env.example` лежит шаблон без секрета.

## Что вызывает модель

Для `matched` запрос к модели не выполняется. Для каждого индикатора со статусом `mismatch`, `needs_review` или `insufficient_data` приложение отправляет отдельный запрос без автоматических повторов. Ответ ограничен тремя JSON-гипотезами. Категории валидируются enum, а каждый evidence token сверяется с токенами текущего результата. Ошибка Polza оставляет детерминированный результат доступным и добавляет диагностический код.

Модель получает только статус, категории, диагностические коды и непрозрачные evidence tokens. Денежные значения, контент документов, названия, IDs документов, строки provenance и пользовательские notes не отправляются. Запросы модели тарифицируются Polza AI.

## Проверка настройки

`GET /health` проверяет только доступность Verification Engine, а не внешнее API. Чтобы проверить модель, отправьте синтетический запрос, который даёт `mismatch`, затем проверьте diagnostics и гипотезы в ответе. API ключ и тело авторизационного заголовка не логируются приложением.

Текущие значения сверялись с [документацией Polza API](https://github.com/polza-ai/docs/blob/main/api-reference/introduction.mdx) и [карточкой Gemma 4 26B A4B](https://polza.ai/models/google/gemma-4-26b-a4b-it). Указанный модельный ID: `google/gemma-4-26b-a4b-it`.
