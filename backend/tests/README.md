# Проверки сложных структур

Запуск: `python -m unittest discover -s backend/tests -v`.

Девять проверок покрывают: PDF-таблицы с границами и без границ; отличие обычных текстовых колонок от таблицы; объединённые ячейки PDF; объединения и вложенные таблицы DOCX; сетку и формулы XLSX; объединение OCR и цифровых страниц; сохранение модельной таблицы среди нативных строк; безопасный HTML-экспорт объединений.

`experiment_docling.py` генерирует два PDF и прогоняет настоящий Docling, объединение геометрии и Markdown. В проверенном окружении модель нашла 0 таблиц, геометрия восстановила по одной в обоих PDF. `experiment_api.py` проверяет загрузку, фоновую обработку и HTML-предпросмотр через работающий API. Его тестовые документы предназначены для временного использования.

Ограничения: поиск таблиц без границ консервативен и требует повторяющихся числовых колонок; полностью текстовая таблица без границ может остаться нераспознанной. Сканы используют результат Docling и OCR. Тест смешанного документа проверяет объединение результатов, а не качество OCR на произвольных сканах. Продолжения таблиц на разных страницах автоматически не сливаются. Для rowspan/colspan и вложенных таблиц Markdown содержит HTML; поддержка зависит от внешнего Markdown-просмотрщика. Сложные произвольные формулы, рукописный текст, многоуровневые сноски и порядок чтения сложной многоколоночной вёрстки этим набором не проверены.

## Реальный корпус и аудит 2026-11-11

Команда `python -m unittest discover -s backend/tests -v` сейчас включает 53 проверки. Помимо синтетики выполнены полный прямой и HTTP-прогоны 30 входных документов (26 из пользовательского архива + IRS PDF, ONS XLSX/CSV, calibre DOCX), проверены браузерные сценарии на реальных сканах и смешанном PDF. Подробный отчёт: docs/document-audit-2026-11-11.md.

- `download_public.py` получает публичные входы и фиксирует их происхождение.
- `run_corpus.py after` выполняет прямой конвейер; ошибка документа делает exit code ненулевым.
- `corpus_server.py` поднимает изолированный тестовый API на 18766, `run_http_corpus.py` проверяет upload/analysis/preview/dedup.
- Приватные входы, извлечённый текст и JSON-отчёты сохраняются в исключённом из Git corpus/.

Уточнение прежних ограничений: borderless detection теперь поддерживает не только числовые колонки, но и короткие пары ключ/значение с явным разрывом. Растровые таблицы с линиями восстанавливаются отдельно от semantic model labels. Автоматического объединения продолжений между страницами всё ещё нет.
